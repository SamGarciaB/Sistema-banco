# Portafolio — Sistema Banco

Este repositorio reúne proyectos de práctica y demostración. El proyecto documentado aquí es **HSBCE-final**, un prototipo independiente de una experiencia web para explorar una solicitud de tarjeta.

## Proyecto destacado

- **[HSBCE-final](HSBCE-final/README.md)** — interfaz adaptable en HTML, CSS y JavaScript, con API en PHP, MySQL, validación de entradas, protección anti-replay, límites de solicitudes y Cloudflare Turnstile.

## Alcance

Este prototipo no es un producto oficial ni está afiliado, patrocinado o aprobado por HSBC o FIFA. Los beneficios y textos de la interfaz son ilustrativos. No ingreses información personal real ni lo uses para ofrecer productos financieros. Consulta el README del proyecto para conocer su configuración, límites y medidas pendientes antes de cualquier uso real.

## Tecnologías

PHP · MySQL · HTML · CSS · JavaScript · Apache
